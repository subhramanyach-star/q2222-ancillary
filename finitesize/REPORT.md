## Findings
1. Structural: in this EAT the test enters only through an affine min-tradeoff function f, i.e. only through the score f.z_hat. So a "full statistics" protocol IS a single-score protocol (score f). Optimising f freely in R^8 contains (b), so (c) >= (b) by construction. This is a theorem about the framework, not a numerical result.
2. Size: c-b <= 7e-7 everywhere (relative 1e-6 to 1e-5, i.e. numerical-optimiser level), apart from eta=0.90 at n=1e12 (2.4e-5 to 2.6e-5, which is about half the asymptotic gap of 5.6e-5). b-a is 4e-4 to 2.8e-2. (c-b)/(c-a) <= 1e-3. Gaining that last part with full statistics needs the optimal single witness anyway.
3. Caveat: at eta=0.90 and n=1e8 (both eps), (a) beats (b) and (c) by 6e-3 to 1e-2, because the lossycone device was tuned for the asymptotic rate (mu_b=1.79, large variance). The device should be co-optimised with n. This does not favour full statistics, because (c) on the same device loses too.
4. Confidence regions: with the right single witness, the 1-D Hoeffding bound beats the 8-D Hoeffding box (union bound) at every point, on both devices, except one tie at eta=.9, opt device, eps=1e-6, n=1e12 (box ahead by 4e-6). The 8-D box/ellipsoid only beats a 1-D bound when that bound uses a suboptimal witness (CHSH at the CHSH device, the BSS 2014 effect). At the CHSH device, the optimal 1-D witness gets back all but ~1e-3 to 1e-5 of the gain.
   Gaussian heuristic: the 8-D ellipsoid beats the 1-D Gaussian only at eta=0.90 on the opt device for n>=1e11 (by 2e-5 to 5e-5). There the asymptotic full-stats gap (5.6e-5) is bigger than the finite-n cost of the extra dimensions. Everywhere else the 1-D bound with the optimal witness wins.
